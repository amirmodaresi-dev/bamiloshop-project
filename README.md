
# Online Store Project

A responsive and interactive e-commerce front-end project built with HTML, CSS, and vanilla JavaScript.

This project was created as a portfolio sample and focuses on building a modern shopping experience with dynamic product sections, a functional shopping cart, and persistent data storage in the browser.

## Features

- Responsive layout
- Hero slider
- Live product search
- Multiple product sections
- Dynamic product cards rendered with JavaScript
- Shopping cart modal
- Add products to cart
- Remove items from cart
- Increase/decrease item quantity
- Automatic cart total calculation
- Cart data saved in `localStorage`
- Toast notifications
- Countdown timer for special offers

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
